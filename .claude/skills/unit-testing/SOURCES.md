# unit-testing の出典

人間が `SKILL.md` の規則を本で確かめるための対応表。エージェントは作業時にこのファイルを読まなくてよい。

定本: Vladimir Khorikov『単体テストの考え方/使い方』（須田智之 訳、マイナビ出版、2022、ISBN 978-4-8399-8172-3）。原著は *Unit Testing Principles, Practices, and Patterns*（Manning, 2020）。目次: https://book.mynavi.jp/ec/products/detail/id=134252

## 本に無い、このリポジトリ独自の規約

「よくあるコードの対応」の表、モックライブラリや差し替え機構を使わず依存を明示的に注入すること、外部 API を包む取得関数を注入して固定データで差し替えること、画面への出力を単体テストの対象から外すこと、テスト名を日本語の文にすること。
