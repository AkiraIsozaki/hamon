## 本に無い、このリポジトリ独自の規約

本の原則を具体的な規約に落とした部分は独自: 実装の継承をしないこと、種類を閉じた集合で表し網羅的に分岐して想定外は例外にすること、「無い」の表現を 1 種類に統一すること、外部データの DTO 分離、公開する関数への型の明示、略語の許可リスト、テスト名以外の識別子を英語にすること。

「型を与える基準」は本（型を強く勧める）と ponytail（先回りを禁じる）の調停で、本の主張そのものではない。
